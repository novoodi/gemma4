## 실행 명령

Gradle `connectedDebugAndroidTest`는 이 환경에서 UTP 오류로 0건 실행되는 일이 있어
**APK 직접 설치 + `am instrument`** 로 우회했다.

```bash
./gradlew assembleDebug assembleDebugAndroidTest
adb install -r -t app/build/outputs/apk/debug/app-debug.apk
adb install -r -t app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument -w -r \
  -e class com.navoodi.morimi.integration.LearningLoopIntegrationTest,com.navoodi.morimi.integration.ScenarioPipelineE2ETest,com.navoodi.morimi.ui.MetricsScreenUiTest \
  com.navoodi.morimi.test/androidx.test.runner.AndroidJUnitRunner
```

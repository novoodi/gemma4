# Ⅲ. 시스템 분석서

> 표지는 중간 보고서 원본 양식을 그대로 사용한다. 작성 방침: **원본 유스케이스의 틀(표 항목·흐름 구조)은 유지하고, 현재 코드(2026-09)와 모순되는 내용만 교정**한다. 아래 각 표에서 【변경】 표시가 붙은 행만 원본과 다르며, 표시가 없는 행은 원본 그대로이다.

> **결정 필요 — 회원탈퇴.** Google Play 정책상 계정 생성 기능이 있는 앱은 **앱 내 계정 삭제 기능**을 반드시 제공해야 한다(출시 차단 요소). 따라서 '탈퇴 기능이 없다'로 문서를 맞추기보다 **탈퇴 기능을 구현하고 원본 유스케이스를 살리는 쪽**을 권장한다(구현 범위: 참여 중인 방 나가기 → `users/{uid}` 삭제 → Firebase 사용자 삭제, 최근 로그인 재인증 필요). 본 초안의 4.1 '탈퇴' 대안 흐름은 **구현을 전제로 작성**했으며, 구현하지 않기로 하면 로그아웃 흐름으로 바꾼다.
